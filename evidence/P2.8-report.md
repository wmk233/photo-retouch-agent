## 三、真实 API 契约核验

对照官方 `https://fal.ai/models/fal-ai/qwen-image-edit/inpaint/api`（及其 `openapi.json` / `llms.txt`）:

- **必填**: `prompt`、`image_url`、`mask_url`
- **可选**: `image_size`（`ImageSize` 或枚举）、`num_images`（默认 1，最大 4）、`output_format`（默认 png）、`sync_mode`、`strength`(0.93)、`acceleration`、`seed`、`negative_prompt`、`enable_safety_checker`
- 官方文档明确允许 Base64 **data URI** 作为文件输入（自动上传只是客户端便利）；`image_url` 与 `mask_url` 可各自为独立 data URI
- 队列流程：`POST https://queue.fal.run/fal-ai/qwen-image-edit/inpaint` → 状态轮询 → 取结果 → 下载输出图
- 计费：**$0.03 / 百万像素**

**当前代码**（`backend/app/providers/fal_inpainting_provider.py:222` `_build_payload`）发送：`prompt`、`image_url`、`mask_url`、`output_format`、`num_images=1`、`sync_mode=False`。

**契约缺口（残余风险）**: 代码**从不设置 `image_size`**（全仓库仅 SiliconFlow 路径引用该字段），而官方文档对默认输出尺寸**未作说明**。若服务返回的尺寸不等于输入 904×1190，`inpaint_verify` 会因尺寸不匹配直接**硬失败**（`restore_kept_pixels` / `verify_inpaint_output` 均不做缩放回退）——这是 fail-closed 的，但意味着**输出尺寸必须由首次付费实测确认**。

两张 data URI 互不相同: ✔ `inputsAreTwoDistinctDataUris = true`。

## 四、最终人物身份保证

- 面部核心必然来自原照片：`restore_kept_pixels` 在 `mask==0` 处**按原坐标**把原图像素复制回来；遇到尺寸或掩膜不匹配时**抛错而非缩放**。
- 三个状态相互独立、不可互相替代：
  - `MASK_VALID`（掩膜通过验收）
  - `PIXEL_IDENTITY_PASSED`（像素身份恢复通过）
  - `VISUAL_ACCEPTANCE_PENDING`（**视觉自然度仍需人工判定**）
- 不以“像素已恢复”宣称视觉效果自然。
